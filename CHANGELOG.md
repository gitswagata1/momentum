# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-10-14

### Added

- AI meeting pipeline: upload audio or paste transcripts
- Auto-transcription via OpenAI Whisper
- Structured MOM generation via Claude AI
- One-click task extraction with assignees, deadlines, and priorities
- JWT-based authentication with role-based access (management / member / FDE / consultant)
- Task management with Pending / In Progress / Completed / Overdue workflow
- Kanban board view
- Email reminders via SMTP and Telegram bot notifications
- Background scheduler (APScheduler) for automated reminder cycles
- Management dashboard with team-wide visibility
- Dark / light mode with glassmorphism UI
- Command palette (Ctrl+K)
- Docker and Render deployment support
- Nginx reverse proxy and systemd service configs
