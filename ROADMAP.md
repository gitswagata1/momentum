# Roadmap

## Vision

Make every meeting end with owners, deadlines and automatic follow-up.

## Milestones

### Now

- [ ] Speaker diarisation in transcripts
- [ ] Calendar integration to attach meetings automatically
- [ ] Evaluation set for task-extraction accuracy

### Next

- [ ] Slack and Teams delivery
- [ ] Recurring-meeting memory: carry unresolved items forward
- [ ] Self-hosted transcription option

### Later

- [ ] Mobile recorder
- [ ] Team analytics on meeting load
- [ ] Enterprise SSO

## Where this can go

| Direction | Idea |
| --------- | ---- |
| **Startup** | Meeting-to-task automation for teams under 200 people, priced per seat. |
| **Publication** | Benchmark action-item extraction from meeting transcripts and measure follow-through rates. |
